# 🎓 College Website Redesign

A modern and fully responsive college website redesign project developed using HTML5, CSS3, Bootstrap 5, JavaScript, AOS Animations, and Font Awesome.

## 🚀 Features

- Responsive Design
- Modern UI/UX
- Video Hero Section
- Notice Board
- About Institution Section
- Admission Section
- Courses Showcase
- Placement Highlights
- Student Testimonials
- Innovation Labs & Research Section
- Smooth Scroll Animations
- Interactive Hover Effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- AOS (Animate On Scroll)
- Font Awesome
